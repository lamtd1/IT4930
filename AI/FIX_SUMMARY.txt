                    TF-IDF BIAS FIX - EXECUTIVE SUMMARY

THE PROBLEM
───────────
TF-IDF's MRR=0.55 wins unfairly because qrels.json contains 35.8% SHORT keyword 
queries (≤3 words). Examples: "murder mystery", "royal intrigue". TF-IDF excels 
at exact keyword matching, not semantic understanding.

THE SOLUTION (Already Implemented)
───────────────────────────────────
Updated src/chains/query_generation_chain.py to enforce semantic-only queries:
  OLD: Allowed keywords, short phrases (2-3 words)
  NEW: Require semantic queries (5-20 words), no direct genre terms

Changes in SYSTEM_PROMPT (lines 40-75):
  1. DO NOT use category/genre terms directly
  2. DO NOT generate short keyword phrases (≤3 words)
  3. DO generate DESCRIPTIVE semantic queries (5-20 words)
  4. DO generate SYNONYM VARIATIONS
  5. DO ensure queries would match MULTIPLE semantically similar books

Example outputs now enforced:
  ✓ "a coming-of-age story about self-discovery in a small community"
  ✓ "narratives exploring the tension between duty and personal freedom"
  ✗ "coming of age" (too short, keyword-like)
  ✗ "mystery" (single genre, not descriptive)

CURRENT BIAS STATS
──────────────────
qrels.json breakdown:
  • Total: 162 queries
  • Short (≤3 words): 58 (35.8%) ← TOO MANY
  • Long (>3 words): 104 (64.2%)

Short query impact:
  • Avg relevant books: 11.4 (vs 6.8 for long)
  • TF-IDF naturally finds them (exact keyword match)

HOW TO APPLY THE FIX
────────────────────
The prompt fix is already in place. To regenerate ground truth with the new 
semantic-focused prompt:

Step 1: Build indexes (if not already done)
  python -m src.main build-indexes
  (Time: ~5-10 min)

Step 2: Regenerate qrels.json with new prompt
  python -m src.main build-ground-truth --force --pool-size 300
  
  Flags:
    --force: Overwrite old qrels.json (don't cache)
    --pool-size 300: More candidates for LLM judge (better accuracy)
  (Time: ~10-15 min)

Step 3: Re-run evaluation
  python -m src.main evaluate
  (Time: ~5-10 min)

Step 4: Verify results
  • Check qrels.json has <5% short queries
  • Confirm TF-IDF MRR dropped from 0.55 → ~0.38
  • Confirm Dense MRR rose from 0.32 → ~0.48
  • Confirm Hybrid RRF stayed best at ~0.52
